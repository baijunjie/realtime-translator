# 使用流程与产品规则

本文描述 Realtime Translator 共享界面在 macOS、iOS 和 Web 上的已实现行为。各端能力与隐私边界见[产品全貌与平台能力](overview.md)。

## 首次启动与母语

首次启动会进入引导页。系统根据设备偏好语言预选中文、日语、英语或韩语；无法匹配时使用英语。用户可在引导中同时确认母语、字号和主题。

“母语”同时决定：

- 应用界面语言；
- 常规翻译的目标语言；
- 中文作为目标语言时的输出字形，统一归一化为简体中文。

完成引导后进入主页。如果当前 ASR 模型已下载，应用会在不申请麦克风权限的前提下后台预热识别引擎。

## 开始一次转写

1. 用户在主页点击录音按钮。主页没有独立的翻译开关；是否翻译由设置中的“翻译方式”决定。
2. 应用检查当前识别模型，以及已启用的本地翻译模型是否就绪。如果缺失，先展示模型名称与体积请求确认。
3. 确认后下载转入后台，主页显示本次录音正在等待的模型进度。可取消“本次录音”的等待，模型仍继续后台下载；所需任务全部成功后，应用自动开始录音。
4. 录音前先显示应用内权限说明，随后才请求系统权限。已拒绝麦克风时，原生端可引导打开对应系统设置；浏览器无法代用户打开站点或系统权限页。
5. macOS 选择系统音频时，首次使用也会先显示说明。由于系统不提供可预查的权限状态，权限拒绝只能在采集失败后识别，再引导到“屏幕与系统音频录制”设置。

录音中，说话时的部分识别结果实时更新；停顿、切段或连续说话过长时，当前内容落为带本地时钟的定稿行。定稿时会优先保留实时识别中较完整、且未被后续稳定结果否定的内容，避免确认时因单次识别波动而无故缩短；已经与后续稳定结果冲突的早期内容不会被带入定稿。iOS 在候选切换时会将文本及其识别语种作为同一结果确定。

只有定稿行会发起翻译、进入归档或参与清屏判定；瞬时的部分识别结果不会被保存。长句被主动切段后，下一行会继续覆盖后续语音并保持时间连续，不会因切段漏掉开头。

## 翻译规则

翻译方式有三种：无、本地、云端。选择“无”即关闭翻译；选择本地或云端即开启翻译。

每个定稿段都独立翻译，译文通过行 ID 异步回填，因此转写不需等待上一行译文。同一语言无需翻译时不显示译文占位；单行翻译失败仅在该行显示失败，不中断识别或其他行。

### 指定识别语言

识别语言被锁定为中、日、英、韩某一种时，非母语定稿段翻成母语。母语段被视为无需翻译，不做反向翻译。

### 自动识别与反向翻译

识别语言为 `auto` 时，翻译目标随本次录音会话调整：

- 识别到非母语时，将该段翻成母语，并记住这一外语；
- 之后识别到母语时，将该段反向翻成最近一次记住的外语；
- 每次新录音会话都清空外语历史，因此会话第一句如果是母语，当时没有反向目标，不显示译文。

系统会依据日文假名和韩文字母修正明显的自动语种误判，但纯汉字文本无法靠字形确定是中文还是日文。短句或语种误判影响结果时，将识别语言锁定为已知语言可避免 `auto` 的语种决策。

## 设置

设置分为四组，修改后自动保存：

- **通用**：母语、主页字号、浅色/深色/跟随系统主题。
- **语音识别**：自动或固定识别语言，以及该平台和语言支持的识别模型。变更语言或模型后，下次录音使用新配置。
- **翻译**：无/本地/云端三态方式；有多个本地模型时可选模型；云端方式可配置 Base URL、模型名和 API Key，并可发起一次最小真实请求测试连通性。Base URL 必须是能接受 `/chat/completions` 的 OpenAI 兼容端点根路径。
- **模型管理**：查看可用的识别/翻译模型、近似或已占用空间、是否已下载以及是否在用，并执行下载、取消、重试或删除。iOS 只列出 ASR 模型，Apple Translation 语言包由系统管理。

macOS 在主页额外显示麦克风/系统音频切换，录音或启停进行中不能切换。

## 模型下载与删除

- 选择未下载的识别或本地翻译模型时，应用会就地询问是否下载。取消确认不会回退已保存的选择，可以在稍后录音时再下载。
- 确认后下载由应用级管理器在后台执行，多个模型可并行下载。离开设置页不会中止任务。
- 在模型管理中取消某个下载，会中止该模型的传输并删除其残留文件，让它回到未下载状态；不影响其他正在下载的模型。
- 模型共用的 Silero VAD 不在选择列表中。并行下载识别模型时公共文件只获取一次，删除单个识别模型也保留 VAD。Web 的 VAD 随应用外壳提供，不从外部模型源下载；首次安装 ASR 模型时仍会从同源资源写入模型缓存，并计入就绪检查与下载进度。
- 当前续传单位是完整文件：重新触发会跳过已下载的完整文件，但半个文件会从头下载；重启应用后不会自动续传，需要用户再次触发。
- 下载器依照模型注册表中的有序源逐个尝试。macOS 和 iOS 的多数模型优先使用项目自托管源并以上游源兜底；macOS 专用 M2M-100 1.2B 只有自托管源。Web 受 CORS 限制，使用可从浏览器访问的上游或镜像源。

## 清屏与归档

主页在存在已定稿行时提供两种处理：

- **删除**：只清空当前主页的转写内容。
- **归档**：先以当前日期时间为默认名称，也可由用户编辑；同名时在默认名后增加序号。保存完成后清空主页。

归档只包含定稿行的本地时间、原文和当时已回填的译文。尚未回填的译文不会在之后自动追加到已保存快照。归档列表按创建时间倒序显示，可查看完整内容或删除单条归档。

## 错误与降级

- 麦克风或系统音频权限拒绝、音频采集失败、音频中断、ASR 初始化失败和识别进程崩溃会结束当前录音，主页显示可本地化的错误提示。已定稿的行仍保留在主页。
- 单行翻译请求失败只结束该行的等待动画并显示失败标记，不停止转写。macOS 翻译子进程异常退出，或 Web 显式预热本地模型失败，会额外显示引擎级警告并结束所有未完成译文的等待动画。Web 在行翻译期间的模型装载或 Worker 运行失败，以及 iOS Apple Translation 不可用，则表现为行级失败，不额外显示引擎级警告。
- iOS 本地翻译在 iOS 18 以下、不支持的语言对或语言包缺失时不会自动把文本发往云端；该行会失败，需由用户明确改选云端翻译。
- 云端翻译需要完整的 Base URL、API Key 和模型名。请求失败或超时时只影响对应行；应用不会在云端与本地翻译之间自动切换。
- 固定识别语言可规避 `auto` 对短段的部分语种误判；将某个语种专用模型删除后，下次使用它录音时会再次请求下载，不会静默改用其他已下载模型。
